# 作品集动效更新 · 2026-11-26

动效参考来自 [Scrolltide Components](https://www.scrolltide.co/components)。个人优势采用 [Card Folder](https://www.scrolltide.co/#c-card-folder) 的文件夹开合交互。

## 效果

- 首屏标题逐行揭幕，介绍与按钮随后进入；增加向下浏览入口。
- 支持 CSS View Timelines 的桌面浏览器中，首屏视频随滚动产生轻微纵深，联系区背景随进入视口归位。不支持时保留静态构图。
- 桌面精细指针下，封面轻微倾斜并带随指针移动的高光；沿用原有第二张图片预览、分类切换与详情页行为。指针更新合并到 requestAnimationFrame，滚动、失焦、离开窗口、路由卸载或媒体条件变化时清理。
- 个人优势采用六张文件夹卡片。鼠标悬停或按下卡片上的箭头时，封面下滑，物件升起并露出背板高光。六项说明可直接阅读，前三项提供相关案例入口。
- 减少动态效果模式下，首屏保留可读的最终状态、停用视差与指针倾斜，展开功能继续可用。

六张优势配图使用内置 ImageGen 生成，保存在 `public/advantages/`，以 480 × 480 透明 WebP 加载。它们是主题插画，实际案例由卡片内的链接打开。

# 第二屏调整建议

以下为改版前的评估。第二屏现已按用户后续提供的 about_B_dark.jpg 实现，当前结构、字体与验证结果见 [改版说明](./README.md)。

390px 本地实测发现 VISUAL DESIGNER 与中文标题发生重叠，应优先修复：取消两者相互依赖的绝对定位 / 固定顶部留白，改为正常文档流排列。白天模式的低透明度人像也影响了画面干净程度。

## 推荐方向

保留真实侧光肖像，改为左侧身份与经历、右侧独立肖像。首屏的屋顶插画负责传达创意，第二屏通过本人身份、职责与经历建立信任。

## 信息顺序

1. 小标：ABOUT / 关于我。
2. 主标题：我是李维，视觉设计师。
3. 简介：十余年设计实践，专注品牌视觉、包装与活动传播。从信息梳理、视觉提案到制作落地，在商业目标与视觉表达之间建立清晰秩序。
4. 主要领域：品牌视觉 / 包装设计 / 活动主视觉 / AI 辅助创意。
5. 工作经历：最近一段优先，展示时间、公司、岗位、职责与已有落地证据。
6. 软件工具作为次级小字，不与主要设计能力混排成同等权重的标签。

## 布局与视觉

- 桌面左侧约60%，肖像约40%；简介和经历处于稳定实底区域。
- 将 VISUAL DESIGNER 缩为辅助英文，避免它先于姓名成为唯一醒目身份。
- 当前主内容起始 padding 292px、简介与经历间距84px，可以改为内容驱动的网格，减少大段顶部空白。
- 正文建议16px、行高1.75；经历正文14–15px，优先保证阅读，不靠照片遮罩维持对比。
- 暗色延续现有近黑、青色与少量金色；白天正文用现有浅色实底，肖像保持独立深色画面。避免当前0.3透明度让人像呈灰色轮廓。
- 手机采用独立肖像区约260–300px高，依次排列简介、领域、经历；不在人物面部上叠正文。
- 不自动缩放肖像，保持第二屏安静，衔接首屏循环视频。
